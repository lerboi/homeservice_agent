# Systems Voco works in

Voco connects to a business's systems for them. The connection is set up by the Voco team during onboarding, with the access the business approves. It is not a one-click self-serve install.

## Groups
- Calendars: Google Calendar, Outlook Calendar, Calendly, Cal.com
- CRM: HubSpot, Salesforce, Pipedrive, Zoho CRM
- Field and practice tools: Jobber, ServiceTitan, Housecall Pro
- Messaging: SMS, WhatsApp, email, Slack
- Payments and accounting: Stripe, Xero, QuickBooks
- Automation and custom: Zapier, Make, webhooks, the business's own REST API

## If a system is not listed
If it has an API or accepts a webhook, the agent can usually work in it. The honest answer for a specific stack comes from a conversation with the team: suggest booking a demo and bringing the list of tools.
