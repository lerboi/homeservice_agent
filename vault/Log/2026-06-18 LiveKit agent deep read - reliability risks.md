**Top risks (prioritized, with file:line):**
1. **Owner-pickup no-answer may DROP the caller instead of falling back to AI.** `dial_status` returns `_empty_twiml()` (twilio_routes.py:321); per Twilio `<Dial action>` semantics an empty action-response hangs up. It records `routing_mode='fallback_to_ai'` (twilio_routes.py:300) but no real fallback happens. Directly contradicts the "never lose a job to voicemail" promise. (Possibly moot if #2 holds.)
2. **Newly-provisioned numbers bypass the FastAPI webhook entirely.** `provisionPhoneNumber` (main repo stripe/webhook/route.js) only associates the SIP trunk, never sets `voiceUrl`. So schedule/VIP/owner-pickup/caps only apply to numbers manually cut over via `scripts/cutover-existing-numbers.js`. New signups may silently lose owner-pickup forwarding. Agent-side subscription gate still works.
3. **Zone/travel-buffer system is dormant.** `zone_id` is always passed `None` into `atomic_book_slot` (book_appointment.py:492) and `candidate_zone_id` never reaches slot calc → every gap uses the flat 30-min default; dashboard-configured zones have no effect on agent bookings. Travel buffer is also enforced BACKWARD only.
4. **Subscription gate revenue leak:** `past_due` with NULL `current_period_end` is allowed forever (subscription_gate.py:41-42, fail-open).
5. **`record_call_outcome` has no durable outbox** (unlike the Stripe meter path) — a transient RPC failure permanently loses the CRM customer/job/inquiry row (post_call.py:310, D-02a forbids fallback).
6. **`language_barrier` is permanently False / non-EN-ES callers mislabeled 'en'** (post_call.py:226-227, 579-608) — latent triage bug.
7. **GC risk:** `asyncio.create_task(_start_egress())` (agent.py:1208) is never assigned to a var → could be GC'd mid-flight → recording silently never starts.
8. **Tests:** atomic double-booking is never exercised (RPC always mocked); some tests use shadow-reimplementations + hardcoded `C:/Users/leheh/...` paths (non-portable, won't run on CI); UAT/Sentry docs are stale Gemini/Phase-60 era, no Phase-66 cascade playbook.
