## How to fetch a transcript from Supabase (one-shot script)

The user has Supabase env in `C:/Users/leheh/.Projects/homeservice_agent/.env.local` with `NEXT_PUBLIC_SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY`. To fetch a call transcript, write a small CJS script at `/tmp/fetch_call.cjs`:

```js
const { createClient } = require('C:/Users/leheh/.Projects/homeservice_agent/node_modules/@supabase/supabase-js');
const fs = require('fs');
const env = fs.readFileSync('C:/Users/leheh/.Projects/homeservice_agent/.env.local', 'utf-8');
const get = (k) => (env.match(new RegExp('^' + k + '=(.*)$', 'm')) || [])[1];
const sb = createClient(get('NEXT_PUBLIC_SUPABASE_URL'), get('SUPABASE_SERVICE_ROLE_KEY'));
(async () => {
  const callId = '<paste call_id here — usually room name from log>';
  const { data, error } = await sb.from('calls')
    .select('call_id, status, transcript_text, transcript_structured, urgency_classification, booking_outcome, disconnection_reason, tenant_id')
    .eq('call_id', callId).single();
  if (error) { console.error(error); process.exit(1); }
  console.log(JSON.stringify(data, null, 2));
})();
```

Then `node /tmp/fetch_call.cjs`.
