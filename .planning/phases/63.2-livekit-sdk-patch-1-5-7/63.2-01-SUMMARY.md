## Plan/Phase Intent

Pure patch-version migration to pick up the 2026-04-30 1.5.7 release on top of Phase 63's 1.5.6 mainline base. **Hygiene + dry-run, NOT a behavior fix.** The 1.5.7 release ships two upstream fixes:

1. `fix(gemini live): use parameters instead of parameters_json_schema for raw schema function tools`
2. `fix: realtime reply generation after interruption`

The 2026-05-05 audit (Explore-agent sweep of `livekit-agent/src/`) confirmed neither fix applies to this stack:

- **Fix #1 does not apply.** All four `@function_tool(raw_schema=...)` call sites already use the standard JSON Schema `parameters` key. Zero references to `parameters_json_schema` anywhere in `src/`.
- **Fix #2 has no code dependency.** No custom interruption-recovery path exists in `src/`; only one diagnostic `@session.on("agent_false_interruption")` log handler at `src/agent.py:582-586`. Reply-after-interruption is fully delegated to Gemini server VAD + the SDK's internal handling.

The phase ships anyway to (a) stay current with upstream patch fixes for unknown bug-class reduction, and (b) maintain the ~30-min ship muscle-memory before the next material upgrade.
