## Decisions Made

- **Captured in wrapper exception handlers as well as `_impl`.** The plan permitted skipping wrapper sites if `deps` was out of scope. In all 3 availability tools the wrapper is the tool function itself with `deps` in closure, so capture was applied — gives Plan 03's replay helper a value even when `_impl` threw before producing one.
- **`check_customer_account.py` captured at the tool function level (single site)** rather than refactoring `format_customer_context_state` (a free function used by both the tool and `prompt._build_customer_account_section`). Keeping the helper pure and capturing once at the tool boundary is cleaner and matches the plan's per-file count requirement.
- **Listener param rename `_event` → `event`.** The leading underscore indicated unused; the Phase 61.3 side-effect now consumes the event payload, so the conventional rename was applied.
